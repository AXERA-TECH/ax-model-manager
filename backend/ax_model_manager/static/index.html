Model Manager Settings

Local model discovery and storage path

Each first-level directory under this path is treated as one model package. Save & Scan persists the path and immediately rescans it.

Changing this path does not move existing models. Stop running models before changing it, otherwise running models may no longer be visible under the new root.

Start model

This package is a one-shot TTS task. It needs text and an output file at request time, so it is not started as a long-running OpenAI-compatible service.
